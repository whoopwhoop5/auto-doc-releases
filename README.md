# Auto Doc

Auto Doc transforme vos modèles Word en documents remplis, en Word et en PDF.

**Télécharger :** dans [Releases](https://github.com/whoopwhoop5/auto-doc-releases/releases/latest), le fichier `AutoDoc-…-windows-x64-setup.exe` (Windows 10 ou 11).

Les mises à jour arrivent ensuite d’elles-mêmes : Auto Doc les propose au lancement.
